GMRES
\[ Ax=b \]
\[ \boxed{x^\star \approx \underset{x\in\mathcal{K}_m}{\operatorname{argmin}} \|Ax-b\|_2} \qquad \text{Krylov subspace} \]
\[ \begin{aligned} &\texttt{function gmres(mvp, rhs)}\\ &\qquad \vdots\\ &\qquad \texttt{return } x^\star \quad \text{(approximate solution)} \end{aligned} \]
Newton's Method
\[ f(x)=0 \]
\[ x^{(k+1)}=x^{(k)}- J^{-1}[f(x^{(k)})] f(x^{(k)}) \]
\[ \boxed{ J[f(x^{(k)})] \Delta x^{(k)}=-f(x^{(k)}) } \]
JVP via Finite Diffrence
\[ J[f(x^{(k)})]\,v \approx \underbrace{ \frac{f(x^{(k)}+\delta v)-f(x^{(k)})}{\delta} }_{f_{\mathrm{diff}}(v)} \]
\[ \begin{aligned} \mathrm{rhs} &= -f(x^{(k)})\\[6pt] \Delta x^{(k)} &= \operatorname{gmres}(f_{\mathrm{diff}},\mathrm{rhs}) \end{aligned} \]
Newton–Krylov Algorithm
\[ \begin{aligned} &\texttt{function newton_krylov}(f_{\mathrm{diff}}, x_0)\\[4pt] &\qquad k \gets 0\\ &\qquad \textbf{while not converged:}\\ &\qquad\quad \Delta x^{(k)} \gets \operatorname{gmres}(f_{\mathrm{diff}},-f(x^{(k)}))\\ &\qquad\quad x^{(k+1)} \gets x^{(k)}+\Delta x^{(k)}\\ &\qquad\quad k \gets k+1\\[4pt] &\qquad \textbf{return } x^{(k)} \end{aligned} \]
Preconditioning
\[ Ax=b \]
\[ \underbrace{M^{-1}A}_{\widetilde{A}}x = \underbrace{M^{-1}b}_{\widetilde{b}} \]

Goal: Improve GMRES convergence by solving an equivalent, better-conditioned system.

Preconditioned Newton–Krylov Algorithm
\[ \begin{aligned} &\texttt{function pnk}(f_{\mathrm{diff}},M^{-1},x_0)\\[4pt] &\quad k \gets 0\\ &\quad \textbf{while not converged:}\\ &\qquad \Delta x^{(k)} \gets \operatorname{gmres} \left(M^{-1}f_{\mathrm{diff}},-M^{-1}f(x^{(k)})\right)\\ &\qquad x^{(k+1)} \gets x^{(k)}+\Delta x^{(k)}\\ &\qquad k \gets k+1\\[4pt] &\quad \textbf{return } x^{(k)} \end{aligned} \]
Applying the Preconditioner

When $M^{-1}$ is not explicitly available, but its action is known, use GMRES to compute the preconditioned vector.

\[ Mz=v \]
\[ \boxed{z=\operatorname{gmres}(w\mapsto Mw,\;v)} \]

Output: $z\approx M^{-1}v$

Preconditioned Newton–Krylov Algorithm
\[ \begin{aligned} &\texttt{function pnk}(f_{\mathrm{diff}},x_0)\\[4pt] &\quad k \gets 0\\ &\quad \textbf{while not converged:}\\ &\qquad z \gets \operatorname{gmres}(w\mapsto Mw,-f(x^{(k)}))\\ &\qquad \Delta x^{(k)} \gets \operatorname{gmres} \left(v\mapsto M^{-1}f_{\mathrm{diff}}(v),z\right)\\ &\qquad x^{(k+1)} \gets x^{(k)}+\Delta x^{(k)}\\ &\qquad k \gets k+1\\[4pt] &\quad \textbf{return } x^{(k)} \end{aligned} \]
Newton–Krylov Algorithm for CC
\[ \begin{aligned} &\texttt{function newton_krylov}(r_{\mathrm{diff}}, \theta_0)\\[4pt] &\qquad k \gets 0\\ &\qquad \textbf{while not converged:}\\ &\qquad\quad \Delta \theta^{(k)} \gets \operatorname{gmres}(r_{\mathrm{diff}},-r(\theta^{(k)}))\\ &\qquad\quad \theta^{(k+1)} \gets \theta^{(k)}+\Delta \theta^{(k)}\\ &\qquad\quad k \gets k+1\\[4pt] &\qquad \textbf{return } \theta^{(k)} \end{aligned} \]
CCSD Preconditioner: Vector Action

Preconditioner action derived in this work for CCSD:

**Singles** \[ 2\left( {}^{v}F^{\lambda}_{\alpha}\theta^{\alpha}_{\mu} - {}^{o}F^{\alpha}_{\mu}\theta^{\lambda}_{\alpha} \right) \]
**Doubles** \[ \begin{aligned} 4\Big( &{}^{v}F^{\lambda}_{\alpha}\theta^{\alpha\sigma}_{\mu\nu} + {}^{v}F^{\sigma}_{\alpha}\theta^{\alpha\lambda}_{\mu\nu} - {}^{o}F^{\alpha}_{\mu}\theta^{\lambda\sigma}_{\alpha\nu} - {}^{o}F^{\alpha}_{\nu}\theta^{\lambda\sigma}_{\mu\alpha} \Big) \end{aligned} \]
Preconditioned Newton–Krylov for CCSD
\[ \begin{aligned} &\texttt{function precond_app} (F_{\mathrm{AO}},\operatorname{dims}(\theta))\\ &\quad \text{Apply the CCSD preconditioner to the input vector}\\ &\quad \textbf{return } \text{precond_vec} \end{aligned} \]
\[ \begin{aligned} &\texttt{function pnk}(r_{\mathrm{diff}},F_{\mathrm{AO}},\theta_0)\\ &\quad k \gets 0\\ &\quad \textbf{while } \|r(\theta^{(k)})\|>\epsilon_{\mathrm{tol}}:\\ &\qquad b \gets -r(\theta^{(k)})\\ &\qquad \text{precond_rhs} \gets \operatorname{gmres}\big( \texttt{precond_app}(F_{\mathrm{AO}},\operatorname{dims}(\theta)), b\big)\\ &\qquad \Delta\theta^{(k)} \gets \operatorname{gmres}\big( v\mapsto \operatorname{gmres}( \texttt{precond_app}(F_{\mathrm{AO}},\operatorname{dims}(\theta)), r_{\mathrm{diff}}(v)), \text{precond_rhs}\big)\\ &\qquad \theta^{(k+1)} \gets \theta^{(k)}+\Delta\theta^{(k)}\\ &\qquad k \gets k+1\\ &\quad \textbf{return } \theta^{(k)} \end{aligned} \]
CCSD Energy Denominators
\[ D_i^a = \varepsilon_i-\varepsilon_a, \qquad D_{ij}^{ab} = \varepsilon_i+\varepsilon_j-\varepsilon_a-\varepsilon_b \]
\[ \begin{aligned} \bigl(D^{-1}r\bigr)_i^a &= \frac{r_i^a}{D_i^a},\\[6pt] \bigl(D^{-1}r\bigr)_{ij}^{ab} &= \frac{r_{ij}^{ab}}{D_{ij}^{ab}}. \end{aligned} \]
\[ \begin{aligned} \text{Singles cost: }&\mathcal{O}(n_o n_v)\\ \text{Doubles cost: }&\mathcal{O}(n_o^2 n_v^2)\\[4pt] \text{Total cost: }&\mathcal{O}(n_o^2 n_v^2) \end{aligned} \]
Preconditioned Newton–Krylov Algorithm
\[ \begin{aligned} &\texttt{function pnk}(f_{\mathrm{diff}},x_0)\\[4pt] &\quad k \gets 0\\ &\quad \textbf{while not converged:}\\ &\qquad z \gets -D^{-1}f(x^{(k)})\\ &\qquad \Delta x^{(k)} \gets \operatorname{gmres} \left(v\mapsto D^{-1}f_{\mathrm{diff}}(v),z\right)\\ &\qquad x^{(k+1)} \gets x^{(k)}+\Delta x^{(k)}\\ &\qquad k \gets k+1\\[4pt] &\quad \textbf{return } x^{(k)} \end{aligned} \]

Git Branch Recovery: The Problem
\[ \begin{aligned} &\textbf{3 months ago:}\\ &\texttt{solvers} \longrightarrow \texttt{main}\\ &\texttt{solvers} \text{ deleted remotely}\\[8pt] &\textbf{3 months later:}\\ &\text{Local copy contains old code + new edits}\\ &\text{Remote } \texttt{main} \text{ has new collaborators' commits} \end{aligned} \]
\[ \boxed{ \begin{array}{c} \text{Local changes to preserve}\\ +\\ \text{Latest remote code to incorporate} \end{array}} \]
The Two Versions Had Diverged
\[ \begin{array}{ll} \textbf{Remote main:} & A \to B \to C \to D \to E\\[4pt] \textbf{Old local:} & A \to B \to C \to X \to Y \end{array} \]
\[ \begin{aligned} D,E &: \text{Collaborators' updates}\\ X,Y &: \text{My local changes} \end{aligned} \]
\[ \boxed{\text{Neither version contained all the desired changes}} \]
Recovery Strategy
\[ \begin{aligned} &\text{Fork the latest repository}\\ &\Downarrow\\[3pt] &\text{Clone the fork}\\ &\Downarrow\\[3pt] &\text{Create a new } \texttt{solvers} \text{ branch}\\ &\Downarrow\\[3pt] &\text{Manually diff the modified files}\\ &\Downarrow\\[3pt] &\text{Apply only the intended changes}\\ &\Downarrow\\[3pt] &\text{Commit and push} \end{aligned} \]
